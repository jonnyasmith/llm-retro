# Inferences run an LLM via a subscription-authed agent CLI inside the job container

**Status:** accepted

Signals stay deterministic ([root ADR-0004](../../../docs/adr/0004-signals-deterministic-inferences-interpretive.md); see #4). **Inferences** are the interpretive, LLM-derived layer, generated by ordinary [self-describing job containers](../../../docs/adr/0002-jobs-as-self-describing-containers.md). The model pass is not a metered API call: the job container invokes a coding-agent **CLI in headless mode** (default `claude --print --output-format stream-json`, input piped on stdin) authenticated by the **host's existing subscription** — an OAuth token minted with `claude setup-token` and injected as the `CLAUDE_CODE_OAUTH_TOKEN` env var. The CLI + model is a per-job `llmretro.job.params` value, stored in Postgres and editable from the web UI. Pattern proven by `~/dev/sandcastle`.

v1 Inferences: three per-session jobs (course-corrections, input-noise waste, dumb-zone *detection*), one image each; a cross-session **thematic synthesis** (LLM, map-reduce over the structured layer — Signals + per-session Inferences, never raw transcripts); and a cross-session **dumb-zone aggregate** (deterministic distribution over the per-session detection points → threshold).

## Considered Options

- **Metered cloud API key (Anthropic/OpenAI).** Rejected as the default: recurring per-call cost over ~2.3k sessions × every re-run, for no quality gain over the subscription-backed frontier model. Remains available as a param override.
- **Local model (Ollama).** Rejected as the default: lower interpretive quality for no benefit once cost and privacy fall away (the sessions are the user's own code, no secrets). Demoted to an optional fallback.
- **One combined model pass emitting all per-session Inferences.** Rejected: couples the prompts and re-runs all three when one changes; violates the "add a job type = ship an image" seam.

## Consequences

- **Zero metered cost, frontier quality, runs entirely local.** Privacy is a non-constraint for this user; the subscription covers the calls.
- **No new mechanism.** Each Inference is a labelled image (root ADR-0002); the cross-session jobs consume the structured layer via the reserved `depends-on`. Adding an Inference never touches existing ones.
- **LLM output breaks the deterministic re-run assumption** (source watermark + idempotent upsert). It is reconciled by:
  - **Stamp-gated recompute** — recompute only when `(model, prompt-version, extractor-version)` or the source session changes; a re-trigger on an unchanged stamp is a no-op, so history is never silently rewritten and no calls are wasted.
  - **Provenance** — each Inference row stores its stamp + the raw model response (or a pointer), so any Inference traces to the exact model + prompt that produced it.
  - **Fail-loud structured output** — single-shot structured mode (tagged block); a malformed response is a bounded-retry then job failure, never a silently-stored partial.
- Inferences are marked **model-derived and non-authoritative**; Signals remain the deterministic source of truth.
- Depends on subscription-auth working headless in a container and on container UID alignment (root ADR-0002 image model) when a CLI needs a bind-mounted credential file instead of an env token.
