# Foundations

The application and Storybook consume the same semantic colour, spacing, radius, and typography tokens.

<div
	style={{
		display: 'grid',
		gridTemplateColumns: 'repeat(3, minmax(8rem, 1fr))',
		gap: 'var(--space-5)'
	}}
>
	{['bg', 'panel', 'panel2', 'accent', 'good', 'warn', 'bad', 'ink', 'muted'].map((token) => (
		<div
			style={{
				background: `var(--${token})`,
				color: token === 'ink' ? 'var(--bg)' : 'var(--ink)',
				border: '1px solid var(--line)',
				borderRadius: 'var(--radius-sm)',
				padding: 'var(--space-6)'
			}}
		>
			<code>--{token}</code>
		</div>
	))}
</div>
